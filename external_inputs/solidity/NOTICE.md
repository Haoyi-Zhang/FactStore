# Public Solidity excerpts

These ten compact excerpts are derived from the MIT-licensed Solidity by Example repository maintained at `https://github.com/Cyfrin/solidity-by-example.github.io`. They are retained only as irregular source text for the deterministic lexical-input exercise. The experiment does not consume vulnerability labels, execute the contracts, or claim that the excerpts represent deployed systems.

The upstream license is reproduced in `LICENSE.upstream`. Each excerpt retains an SPDX MIT notice. Function and contract names ending in `Excerpt` distinguish the bounded consumed text from the complete upstream examples.
