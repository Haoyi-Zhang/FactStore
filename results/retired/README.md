# Retired evidence

The two JSON files in this directory preserve an earlier bounded-history result that enumerated every length-four and length-three history but only the first 19 of 25 length-two histories. It reported 769 histories and was incorrectly described as complete. It is retained as correction evidence and is not a current manuscript input.

Current evidence is generated by `experiments/exhaustive.py`, which enumerates all 25 length-two histories in addition to the 125 length-three and 625 length-four histories. The current result is stored in `results/raw/abstract_crash_cuts.json` and `results/current/tiny-histories/observations.json`.
